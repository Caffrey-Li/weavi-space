# 宣传页

`index.html` 是小围空间的单页宣传页（静态文件，图片在 `assets/`），面向开源用户（GitHub 部署）和公司内部推广两类读者。

- 本地预览：直接用浏览器打开 `site/index.html`。
- 放到 GitHub Pages：仓库设置里 Pages 选 `main` 分支，或把本目录复制到 `gh-pages` 分支根目录。
- 截图来自演示数据（1440×900 @2x 截取后缩到 1600 宽，JPEG），换截图时保持同样的文件名和尺寸。
- 页面里的数字（10 个需求状态、8 个内置能力、9 家模型、30 步 / 20 万 token 等）跟着产品变，功能有变化时一起改。
- 不要放演示账号、密码或真实数据截图。
